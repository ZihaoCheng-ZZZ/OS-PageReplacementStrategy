    Rules

    算法规则与模拟约定

    FIFO 先进先出

    • 按装入顺序排成队列，淘汰队首页面，即驻留时间最长者。
    • 命中不改变队列次序；实现上用“装入时刻”最小者判定淘汰对象。
    • 不看页面近期是否被使用，可能淘汰仍被频繁访问的热页。

    LRU 最近最少使用

    • 淘汰“最久未被访问”的页面，即上次访问时刻最早者。
    • 每次命中都刷新该页的最近使用时刻；缺页装入同样刷新。
    • 精度高但需要记录历史，硬件实现代价大，实际系统常用 Clock 近似。

    Clock 时钟 / 二次机会

    • 页框排成环，每框一位引用位 R；指针初始指向页框 0，表示下一次检查从 0 号框开始。
    • 装入空框：放入指针所指空框，R = 1，指针后移一框（因此依次填满 0、1、2…）。
    • 命中：该页 R = 1，指针不动。
    • 缺页且已满：从指针处循环检查——R = 1 则清零并后移（给第二次机会）；R = 0 则淘汰该页、装入新页、R = 1，指针再后移一框。
    • 最坏扫描两圈必能找到 R = 0 的框；Clock 是 FIFO 的二次机会改进，接近 LRU，但不是栈式算法。
    缺页率缺页次数 ÷ 访问次数
    本页分别展示“当前进度”与完整序列的缺页率。
    命中判定访问页已在页框中
    命中不淘汰；缺页且页框未满时只装入空框，不产生淘汰页。
    模拟约定单进程 · 局部置换
    页框初始为空；页号为非负整数；页框数 2–5；每条序列至多 30 次访问。

    为什么“更多页框”可能更差：FIFO 的驻留集合不满足嵌套关系（不是栈式算法），多一个页框会改变后续所有淘汰决策，缺页数可能上升，称为 Belady 异常。LRU 的驻留集合随页框数嵌套，因此缺页数单调不增；Clock 只用一个引用位近似 LRU，也可能出现异常。
